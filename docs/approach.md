Каждое утро support-отдел получает статусы из CRM и сообщения из рабочих чатов. Сводка считается на момент, который указан на странице, а не по часам компьютера. ИИ читает только текст сообщений: он находит в них факты и дословные цитаты. Срочность ИИ не оценивает и не решает, нужно ли вмешиваться. Срочность считают обычные правила по данным CRM. Список правил показан в разделе «Правила», а сам расчёт записан в файле `packages/core/src/rules/assess.ts`. Главный принцип такой: слова из чата не считаются подтверждением и никогда не понижают срочность. Если ИИ предложил факт без дословной цитаты из сообщения, этот факт отбрасывается и в сводку не попадает. Текст, по которому ИИ читает переписку, лежит в файле `packages/core/prompts/extract-chat-claims.md`. Без ИИ сводка всё равно строится: сообщения показываются сотруднику для ручного чтения, а случай с сообщениями не уходит в «действий не требуется». Так сделано, потому что результат предсказуем, правила проверены тестами, а ИИ используется только там, где без него не обойтись, — в свободном тексте переписки.
